4交通指引

教室位於信義路四段、近基隆路口，鄰近台北 101 與世貿中心。信義區停車位有限，強烈建議搭乘大眾運輸。

捷運

  • 淡水信義線（紅線）「台北 101／世貿站」：出站後沿信義路往基隆路方向（往西）步行約 5–8 分鐘。
  • 「信義安和站」：2A 出口沿信義路四段往東步行約 10–12 分鐘。

公車

  • 搭乘行經信義路的公車（如 信義幹線），於信義路／基隆路口附近站牌下車，步行約 1–3 分鐘。
  • 路線與到站時間建議以「大臺北公車」App 查詢。

停車場

  • 請使用周邊收費停車場，例如台北 101 購物中心停車場、世貿一館地下停車場（步行約 10 分鐘）。
  • 平日上班時段車位緊張，請預留找車位時間；可用「臺北市停車資訊」查即時空位。

5當天課程內容

四門課裡唯一教安裝的一門：從 Claude Code 安裝開始，先做 IG／FB 行銷文案規劃暖身，再一路做到可出圖的系統櫃 3D 規劃平台。

  • Claude Code 從安裝到能用 — 桌面版安裝、登入、介面每一區在做什麼、第一句指令怎麼下
  • IG／FB 行銷文案規劃 — 用中文講清楚你的客群與案例，排出一個月的貼文主題、貼文文案與 Hashtag、限動腳本，整理成可直接複製貼上的排程表
  • 文案改寫與多版本 — 同一個案例一鍵改成專業版、親切版、短版，配合不同平台語氣
  • 系統櫃 3D 規劃平台 — 櫃體型錄 70 款、8 大類；輸入寬、深、高即時重算；透視／等角／立面／平面四種檢視；66 種板材色板
  • 七種匯出 — 透視圖 PNG、平面／立面圖 PDF 與 DXF、三視圖 PDF、3D 模型 DAE、板材明細 CSV、配置檔 JSON
  • 多專案、帳號權限與一鍵上線 — 每個案子各自存檔、管理者與員工分權限，網站上線後平板打開就能用
結業帶走：裝好能用的 Claude Code、一個月份 IG／FB 貼文規劃，以及可以上線的「系統櫃 3D 規劃平台」

  4. 大樓門禁森嚴，進入時請告知管理員為「小樹屋訪客」。
